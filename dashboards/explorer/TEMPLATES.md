# Templates

| Template | Page | Inputs | Shows |
|---|---|---|---|
| Single run | `web/index.html`, `web/templates/single-run.js` | scenario, branch, commit; metric (throughput, p50 latency, p99 latency, memory per key) | The run's Benchmark Fingerprint, with its fields in a drawer. The run's absolute medians, in the sections the scenario defines (set commands: no TTLs, with TTLs, expired but still stored; others: none): one panel per command with a column per shape, mixes grouped inside each shape, on a log axis in absolute units from a reference line at the smallest shape. A column opens its cell: runs, spread, rerun steps. |
| Compare | `web/compare.html`, `web/templates/compare.js` | scenario; series A (branch, commit, slice); series B (branch, commit, slice). The slice is a value of the dimension the scenario declares as variable (set commands: TTL mix); scenarios that declare none have no slice. B's slice defaults to A's; the bar, relative % (default 2) and absolute ns per call (default 20) | Both series' Benchmark Fingerprints and whether they match on every field except repository, commit and the slice, with the fields that differ. One Fail / Pass / Exceed total over the cells on both series: Fail is B slower than A beyond both parts of the bar with every pair the same sign, Exceed the same for faster, Pass everything else. B vs A throughput on the cells both series have, matched on every dimension except the slice: one panel per command with a row per shape, each with the % change and change per call, the bar band, the pairs and its Fail, Pass or Exceed verdict. Cells on only one series are listed once under Not on both. A row opens its cell: both series' raw runs side by side and the rerun steps for each. |

Benchmark Fingerprint: sha256 over the canonical JSON (keys sorted, no whitespace, UTF-8) of the fields in `fingerprint-fields.json` that the run's records carry. A field whose value differs between the run's records takes the sorted list of its values. Fields the source does not record are not hashed and show "not recorded".
