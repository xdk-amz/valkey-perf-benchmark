Method

buildsmerge-base 8c82072a6 (unstable, the merge-base of the PR head) and PR #4959 head 2605393f2, both built on every server host
loadvalkey-benchmark built from the merge-base: -c 50 -P 1 --duration 16, 1 thread, random keys
throughputserver-side: growth of cmdstat calls over growth of server_time_usec in seconds 3-13 of each run, so client-side stalls do not count
pairs and ordersets without TTLs: 5 merge-base/PR pairs, the order alternating each rep on the same host. TTL and expired cells: the mix run against the plain run of the same PR invocation, same host, minutes apart, so host differences cancel
data16-byte members. 4,000,000 sets of 16 members (listpack), 200,000 of 128 (listpack), 400,000 of 512 integers (intset), 1,000 of 100,000 members (hashtable). TTL mixes use a 100,000,000 s TTL, so nothing expires during a run
bara cell fails when all 5 pairs are slower and the median is more than 2% and more than 20 ns per call slower. A cell is faster than the bar by the same rule the other way. Every cell that does not fail passes. The grey band in each chart row is the bar for that row. Memory: 1% and 16 B per set

Harness, placement, network path, gates, window repair and the invalid cells are in method detail in the appendix.
